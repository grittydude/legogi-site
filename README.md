# legogi-site

Public pages for the [L'egogi](https://play.google.com/store/apps/details?id=com.grittydude.legogi) app, served with GitHub Pages:

- `/` — landing page
- `/privacy/` — privacy policy (linked from Google Play and the app)

Keep the privacy policy in step with the app; see the "Update these before new features launch" table in the Play Console answers doc.
